# Football Player Absence Tracking System (FPATS)

System to automate the attendance recording of football players after training sessions using facial recognition.

Development
-----------
Clone the repository
```shell
git clone https://github.com/Arief-AK/FPATS.git
cd FPATS
```

Make sure to develop on the correct branch:
```shell
git fetch
git checkout -b tests/phase1 origin/tests/phase1
```

Ensure that a virtual environment is used:
```shell
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

See how to develop FPATS in the [development](https://fpats.readthedocs.io/en/latest/development/development.html) section of the documentation.
